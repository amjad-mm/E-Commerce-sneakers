# Brag Plan: SOLE//RAW

## What is this app?
SOLE//RAW is an Angular 18 brutalist sneaker store — archival running and lifestyle silhouettes with live cart, wishlist, checkout, and order manifest flow.

## The angle
Treat a working e-commerce app like a military archive dispatch. The joke is the dead-serious engineering language applied to sneakers: propulsion chassis, silhouette telemetry, vault returns. No invented tech — all copy is from the site.

## Hook (first 2-3 seconds)
Black screen. Lime ticker slash. Giant type: “BUILT TO MOVE.” with hard 4px shadow. This is the hero headline verbatim.

## Key moments (the middle)
- The telemetry panel: SILHOUETTE_TELEMETRY // SKU, sneaker stage with corner + marks, cycle pills 01/02/03
- NEW DROPS grid: Pegasus Trail 4 GORE-TEX, Ultraboost Light, Dunk Low Retro — cards arrive one by one, QUICK ADD slam
- The flow: QUICK ADD → BAG (3) → checkout → order placed — simulated cursor click

## Outro / punchline
SOLE//RAW logo lockup. “Move Different.” Final line from footer verbatim.

## User flow worth showing
Browse NEW DROPS → QUICK ADD a Pegasus Trail 4 → BAG count increments → checkout → order manifest placed.

## Tone
- Preset: polished
- Creative direction: brutalist archive product film — engineered hype
- Interpretation: Fewer scenes, longer holds. Confidence through restraint. Soft crossfades. Let the lime/black/cream identity carry it.
